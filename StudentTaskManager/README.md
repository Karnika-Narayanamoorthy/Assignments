# Student Task Management System

## Aim
To develop a Student Task Management System
using the MERN stack.

## Technologies Used
- MongoDB
- Express.js
- React.js
- Node.js
- JavaScript Fetch API

## Features
1. Add Tasks
2. View Tasks
3. Edit Tasks
4. Delete Tasks
5. Set Task Priority
6. Manage Completion Status

## React Hooks
- useState
- useEffect

## Database
MongoDB Database: studentTasks
Collection: tasks

## Execution

Backend:
cd backend
node server.js

Frontend:
cd frontend
npm run dev
